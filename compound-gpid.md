# pipr

## Objective

An interface to compute poverty and inequality indicators for more than 160 countries and regions from the World Bank's database of household surveys, through the Poverty and Inequality Portal (PIP).

## Key Deliverables

- Installable R package (CRAN + GitHub: `devtools::install_github("worldbank/pipr")`)
- API client functions: `get_stats()`, `get_cp()`, `get_cp_ki()`, `get_gd()`, `get_aux()`
- Vignettes: get-cp-example, get-gd-example, get-stats-example, pip-env-aux-tables, reproducible-research, visualization-examples
- pkgdown documentation site (worldbank.github.io/pipr)

## Constraints

- Maintained by: World Bank
- R >= 4.1.0 required
