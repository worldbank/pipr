# Vignettes

<!-- cg:auto:examples -->
The package ships the following vignettes:

- `get-cp-example` — country profile examples
- `get-gd-example` — grouped data examples
- `get-stats-example` — statistics examples
- `pip-env-aux-tables` — PIP environment and auxiliary tables
- `reproducible-research` — reproducible research workflows
- `visualization-examples` — visualization examples
<!-- cg:auto:end -->

<!-- cg:auto:use-cases -->
Vignettes demonstrate common use cases: computing poverty and inequality indicators, retrieving country profiles, and producing reproducible, publication-ready outputs.
